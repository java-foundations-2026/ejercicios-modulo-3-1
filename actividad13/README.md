# JFo 3-1 - Actividad 13

## Simula el estado de un videojuego

Declara variables para jugador, nivel, vida, monedas y si tiene llave.

## Objetivo

- Leer el codigo base y corregirlo o completarlo.
- Ejecutar el programa y comprobar el resultado.
- Ejecutar los tests JUnit para confirmar la autocorreccion.
- Hacer `git add`, `git commit` y `git push`.

## Salida esperada

```text
Jugador: Nova
Nivel: 3
Vida: 85
Monedas: 42
Tiene llave: false
```

## Instrucciones para Eclipse

1. Importa este proyecto en Eclipse como un proyecto Maven.
2. Abre `src/main/java/modulo3_1_actividad13/Actividad13.java`.
3. Corrige o completa el codigo.
4. Ejecuta `Run As > Java Application`.
5. Ejecuta los tests desde `src/test/java/modulo3_1_actividad13/Actividad13Test.java` con `Run As > JUnit Test`.
6. Haz commit y push cuando la actividad funcione.

## GitHub Actions

- El workflow `Java CI` se ejecuta automaticamente en cada `push`.
- Si pasa, el repositorio esta aprobado.
- Si falla, revisa los errores de compilacion o los tests.
